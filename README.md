# Zombie Rage

A free, lightweight top-down zombie survival shooter built for mobile and desktop browsers.

## Play
Survive escalating zombie waves, unlock stronger weapons, build the Rage meter, collect health drops, and defeat a boss every five waves.

## Controls
- Mobile: left-side virtual joystick to move; hold/drag on the right to aim and shoot; tap the Rage bar when full.
- Desktop: WASD/arrow keys to move, mouse to shoot, Space to activate Rage.

## Features
- Mobile multitouch controls
- Desktop controls
- Walker, runner, tank and boss enemies
- Pistol, shotgun, rifle and heavy weapon progression
- Rage mode
- Health pickups
- Wave and boss progression
- Score, kills and persistent local best score
- Sound toggle
- No paid APIs, accounts, analytics or external assets

## Run locally
Open `index.html` in a modern browser, or serve the folder with any simple static web server.

## Deployment
The game is a static site and can be hosted on GitHub Pages, Vercel, Netlify, Cloudflare Pages, or any static host.
